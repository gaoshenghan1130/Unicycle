## Pinout

On the STM32WB55, only SPI is available, so we use an external CAN controller (MCP2515) together with a CAN transceiver (TJA1050) to achieve CAN communication.

**Pinout of SPI on STM32**

| Pin Name   | Pin Number | Function |
|------------|------------|----------|
| SPI1_MISO  | PA6        | Master In Slave Out (MCP2515 → STM32) |
| SPI1_MOSI  | PA7        | Master Out Slave In (STM32 → MCP2515) |
| SPI1_SCK   | PA1        | Serial Clock (generated by STM32) |
| SPI1_NSS   | PA4        | Chip Select: set low to enable communication with MCP2515 |
| SPI_INT    | PA0        | Interrupt pin from MCP2515 to STM32 (signals new CAN messages, errors, etc.) |

**Pinout of CAN Transceiver (TJA1050) and Controller (MCP2515)**

| Pin Name   | Pin Number | Function |
|------------|------------|----------|
| VCC        | 4.75-5.25V         | Power Supply |
| GND        | GND        | Ground |
| CANH       | H    | CAN High Line |
| CANL       | L    | CAN Low Line |
| INT        | PA0        | Interrupt pin to STM32 (signals new CAN messages, errors, etc.) |
| SCK        | SCK        | Serial Clock (from STM32) |
| SI         | SI        | Serial Input (MOSI from STM32) |
| SO         | SO        | Serial Output (MISO to STM32) |
| CS         | CS        | Chip Select (from STM32) | 
| J1         | J1        | Jumpers for resistors 120$\Omega$ |
